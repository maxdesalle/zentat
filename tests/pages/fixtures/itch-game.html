Lancer Tactics

A downloadable game for Windows, macOS, and Linux

Buy Now$20.00 USD or more

A full port of the Lancer TTRPG to a mecha tactics game. Build your squad with some of the best damn customization options ever seen in a tactics RPG & blow up some space cops.

This started as a small excuse for me to learn Godot and feed my love of the Lancer system & universe, but is spiraling out into a full game. I hope you have fun!

This page is for post-Kickstarter early access builds. You can find the original in-browser prototype here.

Note: Lancer Tactics is not intended to be a VTT; neither multiplayer nor human-run GM tools are on the current roadmap. As sick as it might be, good VTTs already exist for Lancer!

Controls

  • WASD: Pan camera
  • Z/C: Zoom camera
  • Q/E: Rotate camera
  • Middle mouse: Free rotate camera
  • R: Toggle overhead view
  • Spacebar/enter: Accept
  • Escape/right click: Cancel
  • Tab: Lock tooltip

Troubleshooting

The most common reason for crashes is an incompatibility between video card drivers and Godot's 3D engine. The game uses Vulkan by default, but you can use the lower-powered OpenGL by running the game in compatibility mode. Windows and Linux have separate shortcuts for the game ("LancerTactics_Compatibility.exe") that will launch it in compat mode — try running that if you run into crashes or odd 3D behavior.

(There's a one-sided arms race between the Godot maintainers and video driver developers where Nvidia et al keep breaking their drivers for Godot and then the maintainers have to scramble a fix)

If you run into other issues or need support, please report them via the ingame link, on the itch.io forums here, or in the Discord.
